# RasPi_FPGA

<a id="readme-top"></a>
RasPi_FPGA is a master project encapsulating all of my open source and open hardware projects that connect a FPGA (Lattice ice40HX4K and ECP5) to the Raspberry Pi 4 and Raspberry Pi 5 for real-time (relatively high-speed) data transfer via GPIO.

[Part 1](./Part1/readme.md) Raspberry Pi 4 with Lattice ice40HX4K FPGA using GPIO.

[Part 2](./Part2/readme.md) Raspberry Pi 5 with Lattice ECP5 FPGA using HDMI and CSI2.
