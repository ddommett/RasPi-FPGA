# UserApp

<a id="readme-userapp"></a>

To make the executable:

```bash
make
```

To program the FPGA (assuming the .bin file from 03-RPi-FPGA-01-FIFO has been built):

```bash
./RPi-FPGA-01 PROG
```

To run the application and have it read data packets from the FPGA:

```bash
./RPi-FPGA-01 LOOP
```
