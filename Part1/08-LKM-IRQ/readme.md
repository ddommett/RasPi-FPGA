# IRQ Based Fast GPIO Bus Kernel Module

<a id="readme-fast-gpio-bus-irq"></a>

To compile the kernel module and produce a .ko file:

```bash
make
```

It will be installed with command:

```bash
sudo insmod fast_gpio_bus.ko
```
